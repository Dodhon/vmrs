# Instructions for Completing VMRS<sup>™</sup> Repair Orders

There are two types of repair orders used with VMRS<sup>TM</sup>:

- The Repair Order (Form 6) and
- The Special Repair Order (*Form 7*)

*Form 6* is primarily intended for fleets which:

- have access to data processing equipment.
- intend to use the equipment to make parts and labor cost calculations for maintenance reporting and accounting purposes.
- perform most maintenance "in-house."

The *Form* 7 is primarily intended for fleets which use manual record keeping systems and for use as a purchase order/repair order record for maintenance and repair services purchased from vendors (out-sourced maintenance).

Both forms serve three basic purposes:

- Provide a document for recording maintenance history data. Coding to the three-digit system level (code key 31) will provide sufficient parts cost information for this purpose.
- Provide a means of recording detailed parts history data for inventory control purposes. Coding at the nine-digit component level (code key 33) is required for this purpose.
- 3. Provide a basic visual record for both shop and statutory purposes in conjunction with the VMRS Equipment File.

# VMRS Repair Order (Form 6) Instructions

The Repair Order (*Form 6*) is a four-part document set consisting of:

- Data processing copy (original)
- Equipment History Jacket (copy)
- Facility File or Vendor Copy (copy)
- Mechanic's Copy (copy)

The following instructions cover preparation of the data processing and mechanic's copies. Instructions preceded by the word "optional" are included for those wishing to compile component code data (code key 33) beyond the system level of detail (code key 31).
