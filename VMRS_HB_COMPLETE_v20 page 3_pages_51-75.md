# Code Key 34: Manufacturer/Supplier/Brand Codes

### Description, Purpose and Use

In order not to disturb either the manufacturers' or suppliers' unique numbering system, VMRS<sup>™</sup> uses its own generic means of identifying manufacturers/suppliers and/or brands. The identifier is a five-character alpha code, assigned by TMC, and used as a prefix to the manufacturers', suppliers' and/or brand unique number. It is not the intent of VMRS to supplant the manufacturers'/suppliers'/brand unique part numbering systems, but rather to supplement them.

When a Code Key 34 manufacturer's code and part number are used in conjunction with the VMRS System/Assembly/Component level codes (Code Key 33), precise identification of a specific part is possible on a universal basis. This commonality of identification on a consistent basis is a prerequisite to developing an industry data base for analysis of maintenance information or for mutually exchanging information on a meaningful basis.

A complete listing of Code Key 34 follows. Companies whose names are in ALL CAPS are legacy assignments to VMRS Code Key 34 made prior to 1997.
