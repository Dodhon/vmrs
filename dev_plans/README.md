# dev_plans/

This folder contains design/architecture plans and implementation plans.

## Scope note
- The rubric below is intended for **architecture/design plans** (especially when changing workflow semantics, storage truth, or release/deploy behavior).
- Implementation-only plans can be lighter weight.

## Standard
- Put new plans in this folder and link them from the associated issue/PR.
- Prefer plans that make decisions explicit and reviewable.

## Rubrics
- Architecture plans should follow: `dev_plans/_rubrics/architecture_plan_checklist.md`
