# **Code Key 32: Assembly Codes**

### Description, Purpose and Use

Through the use of assembly level codes, VMRS provides additional capability to further define Code Key 31's System Codes. The first classification below the system level is referred to as the assembly. At this level, all major groupings within each system are broken out and reported through the use of a three digit code. These, when used with their system prefix, identify the specific assembly within a piece of equipment. For example, front brakes and drums can be identified by a combination of the System and Assembly Code 013-001.

While these codes are the heart of the "common language" of VMRS and are a vital part of the VMRS concept, they are by themselves nothing more than coding conventions designed for use at all levels within the industry—fleets, mechanics, manufacturers, and parts suppliers.
