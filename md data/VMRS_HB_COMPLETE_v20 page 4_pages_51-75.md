# **Code Key 79: Position Codes**

#### Description and Purpose

Position codes apply where multiples of an identical component performing the same function within the VMRS assembly can be installed on the same unit (equipment).

The following rules apply when assigning a "position" code:

- 1. The equipment configuration at the time the work is performed becomes the determining factor when assigning a "position" code. All position codes are based on the drivers seat perspective. The hierarchy is as follows: Front to rear; Left to right; Top to bottom; Sequential.
- 2. Position codes are a function of the specific VMRS assembly being reported.
- 3. When more than one (1) of the same component exists within the hierarchy of a VMRS assembly, then a sequence code must be used.
- 4. Application of "position" codes follows the schema detailed below.
- 5. Position coding is independent of manufacturer's specific numbering convention (example: engines, transmissions, differentials).
- 6. For engines, transmissions and differentials, side planes are defined by the manufacturer's accepted orientation and are installation independent.

Originally, Code Key 79 was a composite of three subsets or elements: Code Key 79a—Side Code; Code Key 79b—Orientation Code; and Code Key 79c—Sequence Code. The original code schema appears at the bottom of this page.

In 2007, TMC's membership approved a restructuring of the coding schema. The updated Code Key 79 defines position through two Code Key subsets or elements: Code Key 79a: Side and Orientation Code and Code Key 79b: Sequence Code.

#### Code Key 79a Side and Orientation Code

This two-digit alpha-numeric code combines the former Side and Orientation elements into one. Codes define the side and orientation (first—front to rear, second—left to right, third—top to bottom; fourth—inner to outer) relative to the driver seat orientation. The code must be considered in conjunction with Code Key 33: Component Code.

#### Code Key 79b Sequence Code

This code remains as originally defined—a numeric, two-digit sequential code. Taken together, these subsets would define position in a four-digit code: Example: 02-01 where

> 02=Front Left 01=Position 1 or First

# Code Key 80: Severity of Service

#### Description and Purpose

Code Key 80 defines severity of service for various types of operations.

| ion |
|-----|
|     |

- 01 Light service, linehaul
- 02 Moderate service, linehaul
- 03 Severe service, linehaul
- 04 Light service, P&D
- 05 Moderate service, P&D
- 06 Severe service, P&D

#### Definitions

#### 01 Light Service, linehaul

- Transportation over long distances in high mileage operations (over 60,000 miles per year.)
- Equipment travels greater than 30 miles between stops.
- Operation on road surfaces of good to excellent concrete or asphalt. (typical)
- Duty is 100 percent load going and 60 percent (or less) load return with grades encountered normally not exceeding eight percent.

#### 02 Moderate Service, linehaul

- Transportation of freight over long distances in high mileage operations (over 60,000 miles per year.)
- Equipment travels greater than 30 miles between stops.
- Operation on road surfaces of good to excellent concrete or asphalt. (typical)
- Duty is loaded full time (more than 60 percent load return) with grades encountered normally not exceeding eight percent.

#### 03 Severe Service, linehaul

- Transportation of freight over long distances in high mileage operations (over 60,000 miles per year.)
- Equipment travels greater than 30 miles between stops.
- Operation on Turnpike only except for loading and unloading at nearby terminals. Road surfaces of good to excellent concrete or asphalt. (typical)
- Duty is loaded full time (more than 60 percent load return) with grades encountered not exceeding three percent.

#### 04 Light Service, pickup and delivery

- Pickup and delivery service within cities and / or suburban areas (short haul, less than 60,000 miles per year).
- Operation on paved road surfaces of concrete or asphalt.
- Grades are defined as light (to about eight percent) which would be typical of geographic areas of operation such as metropolitan Chicago or Detroit.
- Approximately three miles between starts/stops (average). 100 percent load going /40 percent load return (typical).

#### 05 Moderate Service, pickup and delivery

- Pickup and delivery service within cities and / or suburban areas (short haul, less than 60,000 miles per year).
- Operation on paved road surfaces of concrete or asphalt.
- Grades are defined as moderate (to about 12 percent) which would be typical of geographic areas of operation such as metropolitan Atlanta or Seattle.
- Approximately three miles between starts/stops (average). 100 percent load going /40 percent load return (typical).

#### 06 Severe Service, pickup and delivery

- Pickup and delivery service within cities and/or suburban areas (short haul, less than 60,000 miles per year).
- Operation on paved road surfaces of concrete or asphalt.
- Grades are defined as severe (to about 20 percent) which would be typical of geographic areas of operation such as metropolitan Pittsburgh or San Francisco.
- Approximately three miles between starts/stops (average). 100 percent load going /40 percent load return (typical).

# Appendix IIa: Code Key 32 – Assembly Codes (Alphabetical Order)

#### Description, Purpose and Use

Through the use of assembly level codes, VMRS provides additional capability to further define Code Key 31's System Codes. The first classification below the system level is referred to as the assembly. At this level, all major groupings within each system are broken out and reported through the use of a three digit code. These, when used with their system prefix, identify the specific assembly within a vehicle. For example, front brakes and drums can be identified by a combination of the System and Assembly Code 013-001.

While these codes are the heart of the "common language" of VMRS and are a vital part of the VMRS concept, they are by themselves nothing more than coding conventions designed for use at all levels within the industry—fleets, mechanics, manufacturers, and parts suppliers.
